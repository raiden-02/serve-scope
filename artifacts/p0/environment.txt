necessary_args_and_why:
  --gpu-memory-utilization 0.85
    default 0.92 needed 14.71 GiB free; Windows/WSLg already held ~1.2 GiB VRAM
  --enforce-eager
    default inductor compile and FlashInfer JIT asked for nvcc; CUDA Toolkit was not installed
  VLLM_WSL2_ENABLE_PIN_MEMORY=1
    vLLM 0.28 V2 runner requires UVA/pinned memory; WSL default disables it
  VLLM_USE_FLASHINFER_SAMPLER=0
    FlashInfer sampler JIT requires nvcc; native/PyTorch sampler used instead
  user-local gcc 13.3.0 at /home/mayur/.local/gcc
    Triton still needs a host C compiler; sudo apt was not available so gcc was extracted from Ubuntu debs into $HOME
